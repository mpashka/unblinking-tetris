# Запуск под Linux

Эмулятор: [ukncbtl-qt](https://github.com/nzeemin/ukncbtl-qt) — Qt-сборка
UKNCBTL, единственная, которая собирается под Linux.

🚨 На этой машине не собиралось и не запускалось: Qt не установлен, GUI негде
показать. Проверено ровно одно звено — сборка `rt11dsk` из
[ukncbtl-utils](https://github.com/nzeemin/ukncbtl-utils), которой
`make-disk.sh` кладёт игру в образ: она собирается обычным `make` и работает.

## Сборка эмулятора

```sh
sudo apt install build-essential qtbase5-dev qtmultimedia5-dev qt5-qmake
git clone --depth 1 https://github.com/nzeemin/ukncbtl-qt.git
cd ukncbtl-qt/QtUkncBtl
qmake && make -j$(nproc)
```

Эмулятору нужны файлы ПЗУ УКНЦ рядом с исполняемым файлом — их состав описан в
README самого репозитория. Без них машина не стартует.

## Подготовка игры

```sh
emulator/make-disk.sh путь/к/образу.dsk
```

Скрипт сжимает исходник, прогоняет на нём весь набор сценариев и только потом
кладёт `TETRIS.BAS` в образ (предварительно удалив старую копию). `rt11dsk`
он собирает сам при первом запуске.

## Запуск

1. `./QtUkncBtl`
2. `Configuration > Floppy MZ0:` — выбрать образ.
3. В загрузочном меню УКНЦ — «1 — диск», `Enter`. Если попросит дату и время,
   ввести в предложенном формате.
4. Дождаться приглашения БЕЙСИК-системы (`Ok`).
5. `LOAD "MZ0:TETRIS.BAS"`, затем `RUN`.

Управление в игре: `A`/`D` — влево-вправо, `S` — вниз на клетку, `W` — поворот,
пробел — мгновенный сброс, `P` — пауза, `Q` — выход. Работает и раскладка
БК-0010: `7`/`9` — влево-вправо, `8` — поворот, `5` — вниз.

## На что смотреть

Скорость эмуляции должна быть штатной (в UKNCBTL она выравнивается по звуку —
`Emulator > Sound`), иначе замеры `BENCH.BAS` и подобранные по ним задержки
не имеют смысла. Результаты — в матрицу в
[docs/TESTING.md](../docs/TESTING.md).
