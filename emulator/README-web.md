# Запуск в браузере

Два разных способа, и они отвечают на разные вопросы.

## 1. Страница с Бейсиком — играть и править прямо сейчас

`web/tetris-uknc.html` — самостоятельная страница: в ней живёт разборщик того же
подмножества Бейсика, экран 64×24 и **шрифт из ПЗУ УКНЦ**, снятый с самой машины.
Листинг лежит в памяти, его можно править, записывать и запускать: набираете
`RUN` — идёт тетрис. Переключатель рядом меняет немигающую версию на мигающую,
счётчик показывает, сколько знакомест каждая из них перепечатала.

```sh
python3 tools/build_web.py        # собрать из шаблона и обоих исходников
xdg-open web/tetris-uknc.html     # открыть локально, сервер не нужен
```

Это **не эмулятор УКНЦ**: тактов процессора он не считает, а скорость подогнана
под замеренную на машине (около 350 витков главного цикла в секунду). Зато
работает где угодно и запускается мгновенно.

## 2. Настоящий эмулятор в браузере — тот самый УКНЦ

[ukncbtl-wasm](https://github.com/nzeemin/ukncbtl-wasm), готовая страница —
<https://nzeemin.github.io/ukncbtl-online.html>. Он понимает параметры в адресе:

| Параметр | Значение |
|---|---|
| `state=URL` | загрузить сохранённое состояние машины (`.uknc`) |
| `disk0=URL` … `disk3=URL` | подключить образ диска |
| `run=1` | сразу запустить |
| `color=1..3` | палитра |

Файлы качает JavaScript, поэтому действуют правила межсайтовых запросов: образ
должен лежать на сервере, разрешающем доступ.

### Готовое состояние с игрой в памяти

Набирать шестьсот строк руками незачем: безголовая сборка эмулятора набирает их
сама и сохраняет состояние машины.

```sh
tools/uknc/build.sh
cd build/uknc
python3 ../../tools/pack_bas.py ../../src/TETRIS.BAS > T.BAS
./uknc_run --cart romctr_basic.bin --script state.txt   # пишет build/tetris-uknc.uknc
```

Состояние — 229888 байт, ровно тот размер, который принимает браузерная сборка.
Дальше отдайте его по http и откройте:

```sh
emulator/serve-disk.py        # раздаёт build/ с нужным заголовком
```

```
https://nzeemin.github.io/ukncbtl-online.html?state=http://localhost:8000/tetris-uknc.uknc&run=1
```

В машине уже загружен Бейсик и набрана программа: достаточно `RUN`.

🚨 Проверено, что состояние **загружается и запускается** нашей же сборкой
эмулятора (`loadstate` в сценарии). На странице nzeemin.github.io мы его не
пробовали: браузера в том окружении, где всё это собиралось, не было.

## Если хочется набрать программу самому

Картридж с Бейсиком (`romctr_basic.bin` из
[релиза UKNCBTL 2023.1](https://github.com/nzeemin/ukncbtl/releases/tag/release-2023.1))
подключается как ПЗУ-кассета, в загрузочном меню выбирается «2 — кассета ПЗУ».
Дальше — обычный `Ok` и ввод строк. Сжатый вариант программы (`tools/pack_bas.py`)
вдвое короче исходного: 10 килобайт против 20.
