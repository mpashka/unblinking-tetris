# Запуск в браузере

Эмулятор: [ukncbtl-wasm](https://github.com/nzeemin/ukncbtl-wasm), готовая
страница — <https://nzeemin.github.io/ukncbtl-online.html>.

🚨 Ни один шаг ниже на этой машине не выполнялся: браузера здесь нет. Это
инструкция по документации эмулятора, а не протокол успешного запуска. Что
получилось, а что нет — записывать в матрицу в
[docs/TESTING.md](../docs/TESTING.md).

## Что понимает страница эмулятора

Параметры в адресе:

| Параметр | Значение |
|---|---|
| `disk0=URL` … `disk3=URL` | подключить образ диска (`.dsk`, `.rtd`, допускается `.zip` с одним файлом внутри) |
| `state=URL` | загрузить сохранённое состояние (`.uknc`) |
| `run=1` | сразу запустить машину |
| `color=1..3` | палитра (`rgb`, `grey`, `grb`) |

Файлы качает JavaScript, поэтому действуют правила межсайтовых запросов:
открыть страницу «файлом с диска» нельзя, образ должен лежать на сервере,
разрешающем доступ.

## Порядок

```sh
emulator/make-disk.sh путь/к/образу.dsk   # положить игру в образ RT-11
cp путь/к/образу.dsk build/                # чтобы сервер её отдал
emulator/serve-disk.py                     # http://localhost:8000 с нужным заголовком
```

Скрипт печатает готовую ссылку вида

```
https://nzeemin.github.io/ukncbtl-online.html?disk0=http://localhost:8000/образ.dsk&run=1
```

Дальше в самой машине: выбрать в загрузочном меню «1 — диск», дождаться
БЕЙСИК-системы (приглашение `Ok`), набрать

```
LOAD "MZ0:TETRIS.BAS"
RUN
```

Имя устройства зависит от того, в какой дисковод подключён образ; если система
ругается, смотреть [docs/UKNC_BASIC_NOTES.md](../docs/UKNC_BASIC_NOTES.md),
пункт про имя устройства.

## Если образа RT-11 нет

`make-disk.sh` умеет добавлять файл в готовый том, но не создавать том с нуля —
такой команды у `rt11dsk` нет. Взять рабочий образ можно из архивов
УКНЦ-софта ([hobot.pdp-11.ru](https://hobot.pdp-11.ru/)); брать лучше тот же
диск, с которого грузится БЕЙСИК, тогда и подключать нужно только один.

Запасной путь, если с образом не сложилось: БЕЙСИК подключается картриджем ПЗУ
(`Configuration > Cartridge 1`, файл вида `romctr_basic.bin`), а программу
придётся вводить руками. Тогда грузить надо сжатый `build/TETRIS.BAS`
(вдвое меньше исходного), и это всё равно долго — сначала стоит потратить
время на образ.
