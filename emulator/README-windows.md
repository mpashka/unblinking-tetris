# Запуск под Windows

🚨 Не проверялось: машины с Windows под рукой не было. Ниже — то же, что
работает под Linux, в пересказе на windows-лад.

## Эмулятор

[UKNCBTL](https://github.com/nzeemin/ukncbtl/releases) — родная сборка, самая
обжитая. Скачать архив релиза, распаковать, запустить `UKNCBTL.exe`.

## Бейсик из картриджа

1. `Configuration > Cartridge 1` — выбрать `romctr_basic.bin`. Он лежит в архиве
   [релиза 2023.1](https://github.com/nzeemin/ukncbtl/releases/tag/release-2023.1)
   (в свежих релизах его нет, там только exe).
2. В загрузочном меню УКНЦ выбрать «2 — кассета ПЗУ», нажать ввод.
3. Появится `БЕЙСИК УК-НЦ КАССЕТНЫЙ` и приглашение `Ok`.

## Игра в памяти

Проще всего — загрузить готовое состояние машины: `File > Load State` и файл
`tetris-uknc.uknc`, собранный безголовой сборкой (см.
[README-web.md](README-web.md)). Программа уже набрана, остаётся `RUN`.

🚨 В руководстве UKNCBTL сказано, что сохранение и загрузка состояния «пока не
работает». Проверялось наше состояние только безголовой сборкой, где оно
загружается и запускается. Если в окне не выйдет — остаётся набрать программу
руками либо положить её в образ RT-11 утилитой `rt11dsk` из
[ukncbtl-utils](https://github.com/nzeemin/ukncbtl-utils) (под Windows у неё
признак ключа `/`, а не `-`).

## Управление

`A` `D` — вбок, `S` — вниз, `W` — поворот, пробел — сброс, `P` — пауза,
`Q` — выход. Плюс раскладка БК-0010: `7` `9` `8` `5`.
