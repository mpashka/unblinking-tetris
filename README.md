# Немигающий тетрис для УКНЦ на штатном БЕЙСИКе

Тетрис для микро-ЭВМ «Электроника МС 0511» (УКНЦ), написанный на её штатном
БЕЙСИКе так, чтобы движение фигуры не мигало: при сдвиге и повороте
перерисовываются только те клетки, которые действительно изменились, а не вся
фигура целиком.

```
src/TETRIS.BAS      игра
src/KEYTEST.BAS     этап 0: какие коды возвращает INKEY¤
src/BENCH.BAS       этапы 0 и 8: сколько тиков в секунду делает главный цикл
tools/              стенд: интерпретатор Бейсика, сценарии, упаковщик исходника
emulator/           как запустить в браузере, под Linux и под Windows
docs/               язык, устройство игры, проверки, ориентир на БК-0010
AGENTS.md SPEC.md PLAN.md   постановка, спецификация, план и его состояние
```

## Проверить, ничего не устанавливая

```sh
python3 tools/test_tetris.py -v
```

34 сценария выполняют настоящий `TETRIS.BAS` на интерпретаторе подмножества
УКНЦ-Бейсика и проверяют не картинку, а **какие именно клетки экрана игра
трогает**: сдвиг горизонтальной `I` — ровно одно стирание и одна отрисовка,
поворот `T` — тоже, поворот `O` — ноль. Подробности —
[docs/TESTING.md](docs/TESTING.md).

## 🚨 Чего ещё нет

На настоящем БЕЙСИКе УКНЦ игра **не запускалась ни разу**: для этого нужны
эмулятор с образом диска и человек за клавиатурой. Поэтому форма записи
графических операторов, коды клавиш и скорость главного цикла — пока
обоснованные предположения по документации, а не факты. Что именно проверять и
что править, если не сойдётся, — [docs/UKNC_BASIC_NOTES.md](docs/UKNC_BASIC_NOTES.md).
Состояние по этапам — в [PLAN.md](PLAN.md).

## Управление

`A`/`D` — влево-вправо, `S` — вниз на клетку, `W` — поворот, пробел —
мгновенный сброс, `P` — пауза, `Q` — выход. Работает и раскладка тетриса
БК-0010: `7`/`9` — влево-вправо, `8` — поворот, `5` — вниз.

## Как это сделано

Устройство игры, повороты, отбои у пола и стены, задержка фиксации —
[docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Главная особенность языка,
из которой растёт половина решений: **в имени переменной значимы только две
первые буквы**, так что `SCORE` и `SCREEN` для машины — одно и то же.
