# УКНЦ БЕЙСИК: что известно про язык и что ещё надо проверить

🚨 **На живой машине и в эмуляторе не проверялось ничего.** Всё, что ниже
помечено «по документу», взято из «БЕЙСИК. Описание языка» (У1.00031-01 35 01)
и «Руководства оператора» (У1.00031-01 34 02) в оцифровке Emuverse. Раздел
«Проверить на машине» — это и есть этап 0 из [PLAN.md](../PLAN.md): пока он не
пройден, игра считается написанной по документации, а не по факту.

Источники:

- [УКНЦ Бейсик. Описание языка](https://emuverse.ru/wiki/УКНЦ_Бейсик_Описание_языка)
- [УКНЦ Бейсик. Руководство оператора](https://emuverse.ru/wiki/УКНЦ_Бейсик_Руководство_оператора)

## Подтверждено документом

| Что | Как | Где используется |
|---|---|---|
| Экран | `SCREEN N`: 0 и 1 — символьный, 2 и 3 — графический. При переходе между режимами экран очищается | `SM%` в строке 203 |
| Координаты графики | X из `[0,639]`, Y из `[0,263]` | геометрия стакана, строки 201-206 |
| Точка | `PSET @(X,Y)`, `PRESET @(X,Y)` — координаты пишутся с `@` | не используется, всё рисуется через `LINE` |
| Линия и прямоугольник | `LINE [@(X1,Y1)]-@(X2,Y2)[,<цвет>[,B\|BF]]`; `BF` — закрашенный прямоугольник | подпрограммы 8600, 8620, 8650 |
| Цвет | `COLOR [<цвет>],[<фон>],[<бордюр>]`, значения 0..8 | `MC%=8`, палитра фигур в строке 10071 и рядом |
| Очистка | `CLS` — заливка текущим цветом фона | только при старте и после game over |
| Клавиатура | `INKEY¤` — символ или пустая строка, не блокирует | строки 1002, 410, 1403 |
| Код символа | `ASC` — код КОИ-7 | строка 1004 |
| Случайное число | функция `RND` | подпрограмма 2250 |
| Массивы | `DIM <имя>(<размеры>)`, заполняются нулями | строки 210-217 |
| Данные | `DATA`, `READ`, `RESTORE [<строка>]` | таблицы с 10000 |
| Ветвление | `IF <условие> THEN <оператор>\|<строка> [ELSE ...]`, `ON <выражение> GOTO\|GOSUB <список>` | везде; `ON` намеренно не используется |
| Цикл | `FOR <перем>=<от> TO <до> [STEP <шаг>]` … `NEXT` | везде |
| Звук | `BEEP` | пока не используется |
| **Длина строки** | **не больше 255 символов вместе с номером** | проверяется загрузчиком стенда |
| **Значимые символы имени** | **только две первые буквы** | ⚠ главное ограничение, см. ниже |
| Суффиксы типов | `%` целое, `!` одинарная точность, `#` двойная, `¤` символьное | `%` почти везде, `SC` без суффикса |
| Обмен с диском | `LOAD` и `SAVE` — текстовый формат, `CLOAD`/`CSAVE` — внутренний, `BLOAD`/`BSAVE` — двоичный. Пример из документа: `SAVE "TT:PROG1"` | загрузка игры, см. [эмуляторы](../emulator/README-web.md) |
| Приглашение системы | `БЕЙСИК УК-НЦ (ВГУ, 1987.07.08)` и `Ok` | по нему видно, что система та самая |
| Скорость | программа компилируется перед выполнением, а не интерпретируется | почему целые `%` вообще имеют смысл |

### 🚨 Две буквы в имени

Документ: из имени переменной «учитываются только две первые» буквы. Значит
`SCORE` и `SCREEN` — **одна и та же переменная**, и такая ошибка ничем себя не
проявит: программа просто начнёт врать.

Поэтому в `TETRIS.BAS` все имена ровно двухбуквенные, а словарь имён вынесен в
шапку исходника (строки 30-54). Стенд проверяет это механически: интерпретатор
обрезает имя до двух букв и запоминает каждое имя, которое пришлось обрезать,
а сценарий «имена переменных умещаются в две значимые буквы» падает, если
список непустой. Правило удержано кодом, а не обещанием.

## Решения проекта, принятые из-за неопределённости

| Решение | Почему |
|---|---|
| HUD рисуется своим шрифтом 3×5 точками, `PRINT` в игре не используется | документ не обещает, что символьный вывод переживёт графический режим; смешанный режим не гарантирован |
| Надписи хранятся списками номеров знаков (строки 10400+), а не строками | строковый суффикс в КОИ-7 выглядит как `¤`, и чем меньше строк в программе, тем меньше зависимость от него |
| Единственная строковая переменная — `KB¤` под `INKEY¤` | то же самое |
| Вся графика — три подпрограммы 8600, 8620, 8650 | если форма записи `LINE` окажется другой, править надо три строки, а не двести |
| Цвет передаётся аргументом `LINE`, а не оператором `COLOR` перед ней | обе формы есть в документе; вторая записана рядом комментарием на случай замены |
| `ON … GOSUB` не используется, вместо него цепочка `IF` | оператор в документе есть, но цепочка из семи сравнений выполняется один раз на нажатие и ничего не стоит |
| `THEN` всегда содержит ровно один оператор | документ не уточняет, относится ли к `THEN` остаток строки после `:` |
| Время считается тиками главного цикла | часов в языке нет; таблицы задержек — строки 10200+ |

## 🚨 Проверить на машине (этап 0)

Пока это не сделано, любая строка ниже может обрушить программу при первом же
запуске. Порядок проверки — от самого опасного к мелочам.

1. **Какой байт означает строковый тип.** В исходнике стоит `$` (байт 0x24).
   Предположение: в КОИ-7 этот же байт рисуется как `¤`, то есть замены не
   требуется вовсе. Проверяется одной строкой: `10 A$="X" : PRINT A$`.
2. **Графический режим**: `SCREEN 3` или `SCREEN 2` — какой из двух даёт
   640×264 и девять цветов. Правится `SM%` в строке 203.
3. **Форма записи `LINE`**: принимает ли система `LINE @(0,0)-@(10,10),7,BF`.
   Если нет — пробовать без `@` и с `COLOR 7 : LINE @(0,0)-@(10,10),,BF`.
   Правятся строки 8604, 8621, 8651.
4. **Стирание цветом 0**: даёт ли `LINE …,0,BF` фон, а не чёрный поверх фона.
5. **Коды клавиш**: запустить `src/KEYTEST.BAS`, нажать стрелки и рабочие
   клавиши, вписать коды в таблицу строки 10500. Сейчас там `A/D/S/W`,
   пробел, `P`, `Q` и раскладка БК `7/9/8/5`, а под стрелки оставлены четыре
   строки `-1`.
6. **Скорость главного цикла**: запустить `src/BENCH.BAS` с секундомером и
   пересчитать таблицы задержек в строках 10204-10208. Сейчас они рассчитаны
   на ~30 тиков в секунду и это единственное число во всей игре, взятое
   из воздуха.
7. **Помещается ли программа в память**: если ошибка 7 «переполнение памяти»,
   грузить сжатый вариант из `build/TETRIS.BAS` (`tools/pack_bas.py`), он
   вдвое меньше исходного.
8. **Имя устройства при загрузке**: `LOAD "MZ1:TETRIS.BAS"` или другой префикс.
   В документе описан только сетевой `TT:`.

Итог проверки дописывается сюда же: строка переезжает из этого списка в
таблицу «Подтверждено» с пометкой, на какой сборке эмулятора это увидели.
