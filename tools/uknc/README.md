# Безголовый УКНЦ: как машина проверяет программу сама

Эмулятор УКНЦ — оконная программа: человек смотрит, человек нажимает. Проверять
так игру нельзя, поэтому здесь собран тот же эмулятор без окна: сценарий вместо
клавиатуры, PPM-снимок вместо экрана, распознавание вместо взгляда.

```sh
tools/uknc/build.sh                        # собрать (нужен только g++)
cd build/uknc
./uknc_run --cart romctr_basic.bin --script boot.txt
python3 ../../tools/uknc/screen_text.py b2.ppm     # экран как текст
```

## Из чего собрано

| Часть | Откуда |
|---|---|
| ядро эмулятора | [ukncbtl-wasm](https://github.com/nzeemin/ukncbtl-wasm) (Никита Зимин, LGPL) — те же файлы, что и в браузерной сборке |
| ПЗУ машины | `uknc_rom.bin` из того же репозитория |
| картридж с Бейсиком | `romctr_basic.bin` из [релиза UKNCBTL 2023.1](https://github.com/nzeemin/ukncbtl/releases/tag/release-2023.1) |
| драйвер | `headless.cpp` — наш; сценарий, клавиатура, снимки |

Исходники ядра в репозиторий не копируются: `build.sh` забирает их в `build/` и
правит две мелочи, которые есть только у emscripten-сборки. Картридж и ПЗУ —
чужие двоичные файлы, их тоже нет в репозитории; где взять, сказано выше.

## Язык сценария

| Команда | Что делает |
|---|---|
| `frames N` | прокрутить N кадров (25 кадров = секунда машинного времени) |
| `delay N` | сколько кадров держать клавишу; по умолчанию 3 |
| `key ИМЯ` | нажать клавишу: `ENTER`, `SPACE`, `ESC`, `LEFT`, `UP`, буква |
| `raw <код> <0\|1>` | нажать по коду УКНЦ (восьмеричному), второй аргумент — Shift |
| `type ТЕКСТ` | набрать строку |
| `line ТЕКСТ` | набрать строку и нажать ввод |
| `file ПУТЬ` | набрать файл построчно — так в машину попадает программа |
| `shot ПУТЬ.ppm` | снимок экрана |
| `waitchange N` | ждать, пока картинка изменится, и напечатать, сколько кадров прошло |
| `waitregion x1 y1 x2 y2 N` | то же, но следить только за прямоугольником — так меряется время, потому что мигающий курсор портит замер по всему экрану |
| `echo ТЕКСТ` | пометка в журнале |

Пример — загрузиться с картриджа и напечатать программу:

```
frames 150
key 2
frames 30
key ENTER
frames 250
delay 2
file T.BAS
line RUN
frames 900
key SPACE
shot game.ppm
```

Набор шестисот строк занимает около 36 тысяч кадров машинного времени, то есть
пару минут на современной машине.

## Чтение экрана

`screen_text.py` переводит снимок в 64×24 символа. Таблица начертаний снята с
самой машины: программа печатает подряд коды 32..255, снимок разбирается по
знакоместам, каждое подписывается известным кодом.

```sh
python3 tools/uknc/screen_text.py --build font.ppm   # пересобрать таблицу
python3 tools/uknc/screen_text.py снимок.ppm         # прочитать экран
```

Тот же `font.json` идёт в веб-страницу: буквы на ней рисуются шрифтом ПЗУ УКНЦ,
а не системным моноширинным.

## Что этим уже проверено

Раскладка клавиатуры, коды клавиш, отсутствие графики, поведение `COLOR`,
запрет двоеточия, занятые системой имена переменных, скорость главного цикла —
всё в [docs/UKNC_BASIC_NOTES.md](../../docs/UKNC_BASIC_NOTES.md). Обе версии
игры на этой сборке запускаются и играются.
